# Where these class files come from

`svjour3.cls` (v3.2, 2007/05/08), `svglov3.clo` and `spmpsci.bst` were copied on 29 October 2026
from the public template repository github.com/DanySK/Template-LaTeX-Springer-svjour3 (branch
master), because the official Springer zip linked from the IJIS guidelines could not be downloaded
from either machine. Springer holds the copyright and allows their use only for submissions to its
journals.
