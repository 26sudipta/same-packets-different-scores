# Manuscript

## Journal constraints (International Journal of Information Security, Springer)

Read from the IJIS submission guidelines on 28 October 2026. Re-check the live page before upload.

- LaTeX: the guidelines name the Springer `svjour3` class with the `twocolumn` option. The
  official template zip (media.springer.com) could not be downloaded from the container or the
  laptop; `springer/` builds with the Springer Nature `sn-jnl` class for now, and the svjour3 port
  uses a public copy of the class that must be swapped for the official zip before upload.
- Peer review is single blind: author names and affiliations stay in the manuscript.
- Abstract: 150 to 250 words, no undefined abbreviations, no references. The current abstract is
  246 words by `pdftotext` on the flattened PDF (29 October 2026); recount after any edit.
- Keywords: 4 to 6 (the manuscript has 6).
- Use of large language models beyond copy editing must be documented in the Methods section
  (paragraph "Use of AI tools", still for the authors to confirm).
- An extended conference paper needs about 40 percent new content and a disclosure in the cover
  letter. This paper is not an extension of the authors' conference paper, but say so in the
  cover letter if the editor asks.
- No page limit was found on the guidelines page.
- Statements and declarations (funding, competing interests, ethics, data and code availability,
  author contributions) are required; the authors fill the marked items.

## Layout

| Path | What it is |
|---|---|
| `springer/manuscript.tex` | The manuscript (sn-jnl). Sections that are long or shared live in `sections/` and are pulled in with `\input` |
| `sections/` | Method for RQ4 and RQ5, results RQ4 and RQ5, discussion, threats, appendices |
| `tables/` | Generated by `03_Code/make_numbers.py`: `numbers.tex` (every number in the prose as a macro) and every results table. Do not edit by hand |
| `figures/` | Generated by `03_Code/make_figures.py` |
| `springer/submission/manuscript.tex` | Flattened single file for upload, written by `flatten.py` |
| `svjour3/manuscript.tex` | The svjour3 two-column version, written from the flattened copy by `port_svjour3.py`; class files and their source in `svjour3/class/` |
| `highlights.txt` | Five highlights of at most 85 characters, if the journal asks for them |
| `lint_numbers.py` | Fails the build on any number typed in the prose outside a macro or `\litnum`, `\setnum`, `\docnum` |

## Build

```
cd 05_Paper && bash build.sh
```

`build.sh` regenerates the number macros and tables from `04_Results`, lints the prose, compiles
the manuscript, the flattened submission copy and the svjour3 version, reports overfull
boxes, and counts the draft markers (`\pending`,
`\tocheck`, `\VERIFYNUM`), which must all be zero before submission. Running `make_numbers.py`
also writes a manifest into `04_Results/freeze/manifests/`; that file is not part of the frozen
record and should not be committed from an ordinary build.
